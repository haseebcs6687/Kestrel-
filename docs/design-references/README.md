# Design References

## Purpose
This directory contains local-only visual reference screenshots and design notes taken from a licensed third-party admin dashboard template (Minia).

## Strict Policy & Git Hygiene
- **Reference Only**: Used solely for visual direction (spatial cadence, card density, color temperature, and typographic hierarchy).
- **No Assets Committed**: All image files, screenshots, and proprietary design files in this folder are ignored via `.gitignore` (`docs/design-references/*`).
- **No Code Copied**: Under no circumstances should proprietary template code, HTML, CSS, or assets be copied into this project. All frontend components are implemented from scratch using Tailwind CSS and shadcn/ui.
